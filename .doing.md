A guide to supporting football in Japan, covering how to choose a team, buy tickets, attend matches, watch online, travel to stadiums, understand ultra culture, and navigate club life. Includes appendices on J-League resources, Japanese terminology, and stadium listings.

The site is built with Zensical (the successor to MkDocs Material) and deployed automatically to GitHub Pages via GitHub Actions on every push to main. Content lives in docs/ as Markdown files; zensical.toml defines site config and navigation; .github/workflows/docs.yml handles CI/CD. A custom domain CNAME (japanfootball.guide) is included in the docs/ directory.
